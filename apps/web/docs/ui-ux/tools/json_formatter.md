# JSON Formatter

A fast, privacy-focused JSON Formatter, Validator, and Minifier built as part of the **Toolbox** developer utilities platform.

Format, validate, minify, inspect, copy, download, and upload JSON directly from your browser.

> Your JSON is processed locally in the browser and is not sent to a server.

---

## Features

- Format JSON
- Validate JSON
- Minify JSON
- Syntax highlighting
- Line numbers
- Syntax error reporting
- Line and column error location
- Copy formatted JSON
- Download formatted JSON
- Upload `.json` files
- Drag and drop JSON files
- Configurable indentation
  - 2 spaces
  - 4 spaces
  - Tabs
- Sort JSON keys
- JSON statistics
  - File size
  - Number of lines
  - Number of keys
  - Number of arrays
- Local browser processing
- Responsive desktop, tablet, and mobile interface
- Dark-mode-first Toolbox design

---

## Why JSON Formatter?

Working with raw JSON can quickly become difficult when the structure becomes large or deeply nested.

JSON Formatter makes it easier to:

- Read complex JSON
- Find syntax errors
- Debug API responses
- Inspect configuration files
- Format minified JSON
- Validate JSON before using it
- Quickly copy or download formatted JSON
