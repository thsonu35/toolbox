# Homepage Documentation

## Purpose

The homepage is the entry point of the Toolbox platform.

Its primary goals are:

- Explain what Toolbox is.
- Help users quickly find the required tool.
- Build trust through a clean and professional design.
- Showcase the most useful tools and categories.
- Encourage users to explore the platform.

# 2. Hero Section

## Purpose

Introduce the platform within the first few seconds.

## Content

### Heading

One clear sentence explaining Toolbox.

Example

"Everything You Need in One Toolbox"

### Description

Explain the platform in one or two short lines.

Example

"Free online tools for developers, students, creators, businesses, and professionals."

### Primary Button

Explore Tools

### Secondary Button

Browse Categories

### Search Bar

Main search input allowing users to search tools instantly.

Placeholder

"Search for PDF Merge, JSON Formatter, Image Compressor..."

### Popular Searches

Small chips containing:

- JSON Formatter
- Merge PDF
- Image Compressor
- Password Generator
